# Aracari Demo — descargas

Instaladores de **Aracari Demo**, la app de escritorio de ejemplo de Aracari Studios.

👉 **[Descargar la última versión](https://github.com/aracari-studios/aracari-rust-demo-releases/releases/latest)**

| Sistema | Archivo |
|---|---|
| macOS (Apple Silicon e Intel) | `Aracari.Demo_X.Y.Z_universal.dmg` |
| Windows 10/11 | `Aracari.Demo_X.Y.Z_x64-setup.exe` (o `.msi`) |

Una vez instalada, la app avisa sola cuando hay una versión nueva y se actualiza con un clic.

### Primera apertura (la app aún no tiene firma de Apple/Microsoft)

- **macOS:** clic derecho sobre la app → **Abrir** → **Abrir**. Si dice que está dañada:
  `xattr -cr "/Applications/Aracari Demo.app"`
- **Windows:** en SmartScreen, **Más información** → **Ejecutar de todas formas**.
